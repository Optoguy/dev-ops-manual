End goal·reviewed, not scored

Dan runs more projects in parallel than one person could, because every project is operated the same proven way and he is never the bottleneck.

Why
Set by the owner 2026-07-30: ensure all projects are operated consistently, with best practices developed here and shared to every project; own continuous improvement by doing regular external research into new methods of distributed agent work and agent-human collaboration; run regular audits of all projects and share concise actionable findings and recommendations; and keep human communication clear so it saves the founder's time and lets him expand his reach through parallel projects run via agents. Also (2026-07-30): every project, this repo included, must be able to migrate to another AI platform — nothing exclusive to one platform without a clear justification. Reach is the point; the rest are the means.
Done when
A rule learned in one project reaches all of them, and a chat that has read only this repo can run any project correctly without asking how it works. New methods arrive from outside on a deliberate cadence, not by accident. Every project is audited regularly and each audit lands as a short list of findings the owner can act on in minutes. No rule has to be explained twice — and the number of projects he can run in parallel goes up while his hours do not. Moving the whole fleet to another AI platform would be a day of re-pathing, not a rewrite.
Horizon
ongoing — a standing capability, not a milestone with a date
